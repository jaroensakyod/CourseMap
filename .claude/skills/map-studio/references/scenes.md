# Scene catalogue (143 illustrated scenes, style v2)

Use the id in beats.json `panels: [{ "scene": "<id>", "at": "<word>" }]`. Any scene can be placed anywhere (`place`); the
leader line points there. Sound (ambience bed, impact hit) comes with the scene. At most 2 uses of one scene per
episode. Preview sheets: `npm run sb:catalog` → out/catalog/scenes-N.jpg. Never draw a king's face — scenes here
show royalty from behind or far away only.
