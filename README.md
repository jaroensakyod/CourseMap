# CourseMap — ทำคลิปแผนที่เล่าเรื่องด้วย Claude

ชุดเริ่มต้นสำหรับนักเรียน: ทำคลิปประวัติศาสตร์/ข่าวบนแผนที่ดาวเทียมจริง แนวตั้ง 9:16 พากย์ไทย มีซับ เสียงประกอบ
ภาพประกอบเคลื่อนไหว — ทุกเฟรมวาดด้วยโค้ดจากข้อมูลแผนที่เปิด (ไม่ใช้แผนที่ที่มีลิขสิทธิ์)

ตัวอย่างในชุดนี้: **ประวัติศาสตร์บนแผนที่ EP.5 "ทำไมสยามไม่เป็นเมืองขึ้น?"** (10 นาที) พร้อมโค้ดทุกฉาก

## ต้องมี

- คอมพิวเตอร์ Windows 10/11 หรือ Mac · พื้นที่ว่าง ~10 GB · เน็ตเสถียร
- บัญชี **Claude Pro** ขึ้นไป + แอป Claude สำหรับคอมพิวเตอร์ (https://claude.ai/download)
- บัญชี Google (ขอ Gemini API key ฟรี สำหรับเสียงพากย์)

## 4 ขั้นเริ่มต้น

### 1. โหลดชุดนี้ลงเครื่อง

วางโฟลเดอร์ไว้ที่ path สั้น ๆ ไม่มีภาษาไทย ไม่มีเว้นวรรค

- **Windows:** สร้างโฟลเดอร์ `C:\maps` แล้วเปิด PowerShell พิมพ์

  ```powershell
  cd C:\maps; git clone https://github.com/jaroensakyod/CourseMap.git
  ```

- **Mac:** เปิด Terminal พิมพ์

  ```bash
  mkdir -p ~/maps && cd ~/maps && git clone https://github.com/jaroensakyod/CourseMap.git
  ```

ยังไม่มี git? กดปุ่มเขียว **Code → Download ZIP** บนหน้านี้ แตกไฟล์ไว้ที่ `C:\maps\CourseMap` (Mac: `~/maps/CourseMap`)
ก็ได้ — ตัวติดตั้งจะลง git ให้ทีหลัง

### 2. ให้ Claude ติดตั้งให้

เปิดแอป Claude → แท็บ **Code** → เลือกโฟลเดอร์ `CourseMap` แล้วพิมพ์

```
ติดตั้งให้หน่อย
```

Claude จะดูสเปกเครื่องก่อน (การ์ดจอ RAM พื้นที่ว่าง Windows/Mac) แล้วเลือกเครื่องมือและค่าที่เหมาะกับเครื่องคุณ
จากนั้นลง Node.js, ffmpeg, แพ็กเกจ, คลังเสียง, ภาพดาวเทียม และ Whisper ให้ครบ (15–40 นาที ส่วนใหญ่คือรอโหลด)
ถ้ามีหน้าต่างขออนุญาต (Windows) ให้กด **Yes** · Mac ถ้าให้ใส่รหัสผ่านเครื่อง ให้พิมพ์ใน Terminal ตามที่ Claude บอก

> ติดตั้งเองก็ได้: Windows ดับเบิลคลิก `setup\windows.bat` · Mac พิมพ์ `bash setup/mac.sh`

### 3. ใส่ Gemini API key

1. เปิด https://aistudio.google.com/apikey → **Create API key** → คัดลอก
2. เปิดไฟล์ `.env` ในโฟลเดอร์ CourseMap (Claude จะเปิดให้) วาง key ต่อจาก `GEMINI_API_KEY=` แล้ว Save

> **key = รหัสผ่าน** ห้ามแปะในแชต ห้ามแคปลงกลุ่ม ไฟล์ `.env` ไม่ถูกอัปขึ้น GitHub

### 4. สั่งรัน

```
ทดลองทำคลิปตัวอย่าง
```

Claude จะพากย์เสียง จับเวลาคำ และเรนเดอร์ 30 วินาทีแรกของ EP.5 → `out/demo.mp4` ถ้าดูได้ แปลว่าพร้อมทำคลิปของคุณเองแล้ว

## ทำคลิปของคุณเอง

ดูคำสั่งทีละขั้นใน [`docs/PROMPTS.md`](docs/PROMPTS.md) — เริ่มจาก Short 60–90 วินาที แล้วค่อยขยับไปคลิปยาว

### ระบบ storyboard: ทำตอนยาวได้โดยไม่ต้องเขียนโค้ด (ประหยัดโควตา Claude)

แต่ละตอนคือไฟล์ JSON 2 ไฟล์ (`beats.json` บท + ภาพทุกประโยค, `episode.json` สถานที่ สี มุมกล้อง) ระบบวาดให้ทั้งหมด:
แผนที่ดาวเทียม ระบายสีประเทศ หมุด ลูกศร ธง ป้ายข่าว ซับ เสียง และ**ฉากภาพประกอบสำเร็จรูป 143 ฉาก**
(รายการ: `.claude/skills/map-studio/references/scenes.md` · ภาพตัวอย่าง: `npm run sb:catalog`)

| คำสั่ง | ทำอะไร (ไม่ใช้โควตา Claude) |
|---|---|
| `npm run new -- <ช่อง>/<ตอน> "ชื่อตอน"` | สร้างโฟลเดอร์ตอนใหม่ |
| `npm run episode -- <ช่อง>/<ตอน>` | ตรวจ storyboard + ภาพรวมทั้งตอน 1 แผ่น |
| `npm run episode -- <ช่อง>/<ตอน> --voice` | พากย์ + จับเวลาคำ + ภาพรวมใหม่ |
| `npm run episode -- <ช่อง>/<ตอน> --render` | เรนเดอร์จริง (กันล่ม) + ซับ |

ตัวอย่างสั้น 6 ประโยค: `src/episodes/examples/ayutthaya-island/`

| คำสั่งที่ใช้บ่อย | ทำอะไร |
|---|---|
| `npm run doctor` | ตรวจว่าเครื่องพร้อมไหม |
| `npm run demo` | ทดลองทั้งสายการผลิต (30 วินาทีแรกของ EP.5) |
| `npm run dev` | เปิด Remotion Studio ดูและปรับแบบสด |
| `npm run render:chunks -- Ep05Clear out/ep05.mp4 --loudness --glitch` | เรนเดอร์คลิปยาวแบบกันล่ม (ล่มแล้วรันคำสั่งเดิมซ้ำ จะต่อจากที่ค้าง) |
