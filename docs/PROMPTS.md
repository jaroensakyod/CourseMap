# คำสั่งให้ Claude — ก๊อปไปวางทีละข้อ

เปิดแอป Claude → แท็บ Code → โฟลเดอร์ `CourseMap` แล้ววางตามลำดับ
**รอให้ Claude ทำข้อก่อนหน้าเสร็จ และตอบคำถามของมันก่อน** ค่อยวางข้อถัดไป
ตรงที่อยู่ใน [วงเล็บเหลี่ยม] ให้เปลี่ยนเป็นเรื่องของคุณ

> ประหยัดโควตา Pro: เลือกโมเดล **Sonnet** เป็นหลัก · 1 คลิป = 1 session (เริ่ม session ใหม่ทุกคลิป) · เริ่มจาก Short

## 1. บรีฟ + บท (ด่านอนุมัติที่ 1)

```
ทำคลิป Short แนวตั้ง 9:16 ยาว 60 วินาที ตามมาตรฐานช่อง (สไตล์ข่าว clear layout แบบ EP.5) เรื่อง [ทำไมกรุงเทพฯ น้ำท่วมง่าย]
พากย์ไทยด้วย Gemini TTS เปิดด้วยประโยคช็อกไม่เกิน 30 ตัวอักษร ภาพแรงตั้งแต่เฟรมแรก
ตรวจข้อเท็จจริงลง sources.md แล้วเขียนบทเป็นตาราง beat ให้ดูก่อน ยังไม่ต้องสร้างอะไร
```

แก้บทได้ เช่น `beat 2 ยาวไป ตัดให้สั้นลง` แล้วพอใจค่อยพิมพ์ `บทผ่าน`

## 2. ภาพตัวอย่าง (ด่านอนุมัติที่ 2)

```
ดึงข้อมูลแผนที่ที่บทใช้ แล้วเรนเดอร์ภาพนิ่ง 3 ฉากสำคัญให้ดู ใช้ฉากและชุดเครื่องมือที่มีอยู่แล้วก่อน
```

ติได้ เช่น `ฉาก 2 ซูมเข้าอีก` `ตัวหนังสือใหญ่ขึ้น` พอใจแล้วพิมพ์ `ภาพผ่าน`

## 3. เสียงพากย์ + ซับ

```
ทำเสียงพากย์ด้วย Gemini TTS (BATCH) แล้วจับเวลาคำด้วย whisper + snap-words ให้ซับและภาพเปลี่ยนตรงคำ
```

## 4. เรนเดอร์ทดสอบ 10 วินาที

```
เรนเดอร์ช่วงที่เสี่ยงที่สุด 10 วินาทีให้ดูก่อน แล้วตรวจ check-glitch
```

## 5. เรนเดอร์จริง + ของส่งมอบ (ด่านอนุมัติที่ 3)

```
เรนเดอร์ทั้งคลิปด้วย render:chunks (--loudness --glitch) แล้วทำซับ .srt คำบรรยายคลิปพร้อมเครดิตแผนที่ และภาพปก
```

ไฟล์ทั้งหมดอยู่ในโฟลเดอร์ `out/` — **คุณอัปโหลดเอง** Claude จะไม่อัปขึ้นโซเชียลให้

## คำสั่งที่ใช้บ่อย

| อยากได้ | พิมพ์ |
|---|---|
| ดูแบบสด ปรับเองได้ | `เปิด remotion studio ให้หน่อย` |
| เรนเดอร์ค้าง/ล่มกลางทาง | `เรนเดอร์ล่ม ต่อจากที่ค้างให้หน่อย` (รันคำสั่งเดิมซ้ำ ไม่เริ่มใหม่) |
| ภาพบังแผนที่ | `ใช้ clear layout ตามกฎข้อ 9` |
| ตอนต่อไปหน้าตาเหมือนเดิม | `ล็อกสไตล์นี้ไว้ใช้ทุกตอน` |
| เสียงไม่ชอบ | `ขอฟังเสียงพากย์ตัวอื่น 3 แบบ` |
| มี error | `มี error แบบนี้ ช่วยแก้: [วางข้อความ error]` |
| การ์ดจอ NVIDIA อยากเร็วขึ้น | `ตั้ง whisper แบบ CUDA ตาม audio.md` |
| ดูว่าใช้ Gemini ไปเท่าไหร่ | `npm run cost` |

## กฎที่ Claude ทำตามเสมอ

- หยุดรออนุมัติ 3 ครั้ง: บท → ภาพตัวอย่าง → คลิปจริง
- ไม่อัปโหลดอะไรขึ้นโซเชียลแทนคุณ · ไม่ขอ API key ในแชต
- ใช้เฉพาะข้อมูลแผนที่ที่มีสิทธิ์ใช้ และใส่เครดิตในคำบรรยาย
- พรมแดนในอดีต เส้นทางทัพ ขึ้นป้ายว่า "โดยประมาณ"
