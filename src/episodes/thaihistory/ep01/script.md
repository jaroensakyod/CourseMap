# ประวัติศาสตร์บนแผนที่: เสียกรุงศรีอยุธยา (คลิปเดียวจบ)

รูปแบบ: คลิปยาวแนวตั้ง 9:16 ราว 10 นาที ต่อเนื่องคลิปเดียว ไม่มีการ์ดคั่นบท ไม่มี "ตอนที่"
เสียง: ผู้เล่าคนเดียว (Charon) + เสียงพระยาตาก 1 ประโยค · TTS `gemini-3.8-flash-lite-tts`
บทราว ~5,800 ตัวอักษร (เล่าช้าแบบคุย เว้นจังหวะบ่อย ≈ 10–10.5 นาที)

## แนวทาง (ตามคลิปอ้างอิง ปรับเป็นของช่องเราเอง)

**วิธีเล่า**
- เปิดด้วย**สถานการณ์ที่ดูแปลก** → "คำถามของวันนี้ครับ" → "ไปดูกันครับ" ทั้งคลิปเดินไปหาคำตอบข้อเดียว
- คุยกับคนดู มี "ครับ" มีมุกเล็ก ๆ 4–5 จุด คนเล่ามีตัวตน ("ผมขอเรียกสั้น ๆ ว่า…")
- ใช้**ภาพตัดขวาง** 3 ภาพอธิบายกลไก (คำตอบของคำถามหลักอยู่ในภาพพวกนี้)
- **ควิซ** 2 จุดระหว่างเรื่อง + **คำถามให้คนดูเลือก**ตอนปิด (ดึงคอมเมนต์)

**หน้าจอ (ระบบเดียวทั้งคลิป)**
- แผนที่กระดาษสีครีม แม่น้ำสีฟ้าอมเขียวมีขอบตลิ่งน้ำตาล ขอบจอมืดลงนิด ๆ
- **ไอคอนการ์ตูนแบนเส้นขอบเข้ม** ขยับได้: เรือ ทหารไทย/พม่า ช้าง ปืนใหญ่ ค่ายสี่เหลี่ยมมีบ้าน ค่ายวงกลมไม้ระเนียด ธง เมฆฝน
  พระอาทิตย์ ไฟ เจดีย์ ต้นข้าว กระสอบข้าว โซ่ หม้อข้าว จอบ ฟืน มงกุฎ ม้า
- สีฝ่าย: อยุธยา = น้ำเงินคราม · พม่า = แดงชาด · พระยาตาก = ทอง · ชาวบ้าน = เขียว
- **มุมซ้ายบน** ป้าย "พ.ศ. ____" (+ เดือนเมื่อสำคัญ) · **มุมขวาบน** แผนที่ไทยจิ๋วมีกรอบจุดที่กำลังดู
- **การ์ดล่าง** ทุกช่วง: หัวข้อตัวหนา + บรรทัดรอง แถบซ้ายเป็นสีฝ่ายที่กำลังพูดถึง
- การ์ดคำพูดพงศาวดาร (กระดาษ + เส้นแดง) · ช่องการ์ตูนตัวละคร 3 ช่อง (ชาวบ้านบางระจัน, พระยาตาก, ทหารพม่า)
- ต่างจากคลิปอ้างอิง: สีกระดาษ/ฟ้าของเราเอง ตัวการ์ตูนออกแบบเอง และ 3 วิแรก**มีการเคลื่อนไหวแรง** (ฝนตก น้ำแผ่ ค่ายพม่าโผล่) ไม่ใช่ภาพนิ่ง

คอลัมน์ "การ์ดล่าง" = หัวข้อ / บรรทัดรอง · *(ประมาณ)* = ตำแหน่งโดยประมาณ (ใส่ในคำอธิบายคลิป ไม่ขึ้นจอ)
