## ชั้นข้อมูลแผนที่ที่ต้องใช้
- ประเทศ/แผ่นดิน: world-atlas (Natural Earth, public domain)
- จังหวัดไทย: `npm run data -- THA`
- แม่น้ำ: `npm run osm -- ayutthaya ... rivers` (เกาะ + 3 แม่น้ำ) และ `npm run rivers` (ภาคกลาง)
- ภาพนูน DEM ภาคกลาง + เทือกเขาตะนาวศรี (ฉากน้ำท่วม / ค่ายบนที่ดอน)
- พรมแดนประวัติศาสตร์ ~1700 (`npm run history -- 1700`) สำหรับอยุธยา ล้านนา อังวะ
- ภาพดาวเทียม NASA เกาะอยุธยาปัจจุบัน
