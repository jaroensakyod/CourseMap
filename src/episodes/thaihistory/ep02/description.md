# คำอธิบาย

ทหารไม่กี่พัน รวม 5 ก๊กได้ไง? 🔥

หลังกรุงศรีอยุธยาแตกในปี 2310 แผ่นดินแตกเป็น 5 ก๊ก ก๊กที่เล็กที่สุดและไม่มีเชื้อเจ้าคือก๊กพระยาตากที่จันทบุรี แต่ใช้เวลาราว 3 ปีก็รวมแผ่นดินได้ทั้งหมด
คลิปนี้พาไปดูบนแผนที่ดาวเทียมจริงว่า
⛵ ทำไม "เรือ" คืออาวุธลับของพระเจ้าตาก
🏯 ทำไมไม่ฟื้นอยุธยา แต่ตั้งเมืองหลวงที่ธนบุรี
⚔️ ศึกบางกุ้ง พิษณุโลกครั้งแรกที่แพ้ และกลับไปชนะในครั้งที่สอง
🗺️ ตีพิมาย นครศรีธรรมราช และเจ้าพระฝาง ทีละก๊ก จนสีทองครอบคลุมทั้งแผ่นดิน
